# IntelliAPI

このプロジェクトは、HTAやHTML/JSコード向けにリアルタイム補完を提供する AI補完サーバー です。
Pythonで実装され、FastAPIを使ってHTTP経由でC#などのクライアントから呼び出せます。

目的：ユーザーが快適にコードを書けるよう、AIによる補完やチャット機能を提供

モデル構成：

Intelli1.1.2 / Intelli1.1.3：標準コード補完用モデル

IntelliChat：会話・説明補助用の軽量モデル

# 英語(English)

This project is an AI completion server that provides real-time completion for HTA and HTML/JS code.
It is implemented in Python and can be called from clients such as C# via HTTP using FastAPI.

Purpose: To provide AI completion and chat functionality to help users write code comfortably.

Model Configuration:

Intelli1.1.2 / Intelli1.1.3: Standard code completion model

IntelliChat: Lightweight model for conversation and explanation assistance
